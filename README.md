# Otaku List

A simple and elegant anime list manager that helps you track your watching progress. Built with vanilla JavaScript and Bootstrap.

## Features

- Grid and List view modes
- Search anime from Jikan API (MyAnimeList)
- Track watching progress
- Import/Export list functionality
- Import from MyAnimeList XML
- Responsive design for mobile devices

## Live Demo

Visit [GitHub Pages](https://iqbalpti22.github.io/Otaku-List/) to see the live demo.

## Built With

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- [Jikan API](https://jikan.moe/) - Unofficial MyAnimeList API
